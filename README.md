Judul Proyek
# 💀 The Ultimate Brainrot Detector

# 📌 Deskripsi Proyek
The Ultimate Brainrot Detector adalah program kuis interaktif
berbasis bahasa pemrograman Pascal yang dirancang untuk menguji
seberapa tinggi tingkat brainrot pengguna melalui serangkaian
pertanyaan yang menarik dan menghibur.

Pengguna akan menjawab pertanyaan yang tersedia, kemudian program
akan memproses jawaban dan menampilkan hasil akhir berdasarkan
skor yang diperoleh.

Proyek ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS)
Praktikum Dasar Pemrograman.

# ⚙️ Fitur Utama Program

1. **Interactive Quiz**
   Menampilkan pertanyaan yang harus dijawab oleh pengguna.

2. **User Input**
   Memungkinkan pengguna memasukkan jawaban.

3. **Score Calculation**
   Menghitung skor berdasarkan jawaban pengguna.

4. **Brainrot Level**
   Menampilkan tingkat brainrot pengguna berdasarkan skor akhir.

5. **Conditional Statements**
   Menggunakan percabangan untuk memeriksa jawaban dan menentukan
   hasil kuis.

6. **Looping**
   Menggunakan perulangan untuk menjalankan proses kuis jika
   diterapkan dalam program.

## 🧠 Logika Program

Program dimulai dengan menampilkan judul dan petunjuk permainan.
Pengguna kemudian menjawab pertanyaan yang diberikan.

Setiap jawaban diproses menggunakan logika percabangan.
Skor diperbarui sesuai dengan aturan penilaian yang ditentukan.
Setelah semua pertanyaan selesai, program menghitung hasil akhir
dan menampilkan tingkat brainrot pengguna.
